变频电机传送带

发表于2026-06-11|更新于2026-06-12|PLC 学习
|浏览量:


这段可以理解成：PLC 通过 Modbus 给 20 号变频器写入频率值，让变频电机传送带按设定速度运行。
先看整体流程：
设定频率 #hz
↓
把频率换算成变频器能识别的数值
↓
通过 Modbus 写到变频器寄存器 40101
↓
变频器按这个频率控制电机速度
↓
传送带速度跟着改变

  1. 通讯初始化
    “MB_COMM_LOAD_DB”(REQ:=1,
    “PORT”:=269,
    BAUD:=9600,
    MB_DB:=”MB_MASTER_DB”);

含义：
参数 含义
REQ:=1 一直请求初始化通讯
“PORT”:=269 PLC 使用的串口/通讯口编号
BAUD:=9600 通讯波特率，和变频器参数要一致
MB_DB:=”MB_MASTER_DB” 指定 Modbus 主站功能块用的背景 DB

简单说：
这段是让 PLC 准备好 Modbus 通讯。
PLC 要和变频器说话，先要把通讯口、波特率设置好。
实际项目里，MB_COMM_LOAD 一般建议只在首次扫描时执行，例如：
REQ := “FirstScan”
不要每一扫描周期都初始化一次。
2. Modbus 写变频器
“MB_MASTER_DB”(REQ:=1,
MB_ADDR:=20,
MODE:=1,
DATA_ADDR:=40101,
DATA_LEN:=1,
DATA_PTR:=#pl);
含义：
参数 含义
REQ:=1 一直执行 Modbus 请求
MB_ADDR:=20 变频器的 Modbus 从站地址是 20
MODE:=1 写数据到变频器
DATA_ADDR:=40101 写入变频器的 40101 寄存器
DATA_LEN:=1 写 1 个寄存器
DATA_PTR:=#pl 把 #pl 这个值写进去

也就是说：
PLC 把 #pl 的数值，写到 20 号变频器的 40101 地址。
40101 这个地址一般是变频器的频率给定地址。
但是要注意：40101 具体是不是频率给定，要看你的变频器说明书。
不同品牌的变频器，频率地址可能不一样。
3. 频率换算
#pl := INT_TO_BCD16(REAL_TO_INT(#hz / 50 * 16384));
这一句是关键。
它的意思是：
把设定频率 #hz，换算成变频器需要的数字量 #pl。
公式：
#pl = #hz / 50 * 16384
可以这样理解：
频率 #hz 换算结果
0 Hz 0
25 Hz 8192
50 Hz 16384

也就是：
50Hz 对应 16384
25Hz 对应一半 8192
0Hz 对应 0
所以这段程序是在做比例换算：
你想让变频器跑多少 Hz
PLC 就换算成一个 0 到 16384 的数
然后写给变频器
REAL_TO_INT 的意思：
把实数转成整数
比如：
25.6 -> 26 或 25，具体看转换规则
INT_TO_BCD16 的意思：
把整数转成 BCD 格式
这个要特别注意：不是所有变频器都需要 BCD 格式。
有些变频器要普通整数，有些才要 BCD。这个要看说明书。
4. 举例理解
假设：
#hz := 30.0;
那么：
30 / 50 * 16384 = 9830.4
转成整数大约是：
9830
再转成 BCD 后，放到：
#pl
然后 PLC 通过 Modbus 把 #pl 写到变频器 40101。
结果就是：
变频器收到 30Hz 的速度给定
电机按 30Hz 转
传送带中速运行
5. 这段程序代表的设备动作
#hz 越大
↓
#pl 越大
↓
写给变频器的速度值越大
↓
电机转得越快
↓
传送带跑得越快
#hz = 0
传送带停止或速度为 0

#hz = 25
传送带半速运行

#hz = 50
传送带满速运行
不过这段代码只是在写频率，不一定包含“启动变频器”的命令。
很多变频器还需要另外写一个运行命令，比如：
正转启动
停止
复位
如果现场传送带不动，要检查有没有单独的启动命令寄存器。
6. 建议写法顺序
你现在是先写 Modbus，再计算 #pl：
“MB_MASTER_DB”(… DATA_PTR:=#pl);

#pl := INT_TO_BCD16(…);
这样本扫描周期写出去的是旧的 #pl。更清楚的写法是：
#pl := INT_TO_BCD16(REAL_TO_INT(#hz / 50.0 * 16384.0));

“MB_MASTER_DB”(REQ:=1,
MB_ADDR:=20,
MODE:=1,
DATA_ADDR:=40101,
DATA_LEN:=1,
DATA_PTR:=#pl);
意思是：
先算好速度值
再写给变频器
