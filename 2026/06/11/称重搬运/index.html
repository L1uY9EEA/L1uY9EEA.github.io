称重搬运

发表于2026-06-11|更新于2026-06-12|PLC 学习
|浏览量:

城中搬运的流程


这段程序的核心意思是：
先通过 Modbus 读取称重仪表重量
然后根据触摸屏指令：
221：记录第一次重量，作为底重/皮重
222：再次称重，用当前重量 - 底重 = 净重

  1. 通讯部分
    “MB_COMM_LOAD_DB”(REQ:=”FirstScan”,
    “PORT”:=269,
    BAUD:=9600,
    MB_DB:=”MB_MASTER_DB”);

这一段是初始化 Modbus 通讯。
意思是：
PLC 和称重仪表建立串口通讯
波特率 9600
只在第一次扫描 FirstScan 时初始化一次
下面这一段是读称重仪表的数据：
“MB_MASTER_DB”(REQ:=1,
MB_ADDR:=6,
MODE:=0,
DATA_ADDR:=40001,
DATA_LEN:=2,
DATA_PTR:=#cz3);
意思是：
从 6 号称重仪表读取数据
读取地址 40001
读取 2 个寄存器
读回来的重量放到 #cz3 里面
所以 “块_1_DB”.cz3[0] 就是你后面拿来用的重量值。
2. 定时器部分
#s(IN:=1,
PT:=t#1.5s);

IF #s.Q THEN
RESET_TIMER(#s);
#j += 1;
END_IF;
这一段相当于：
每过 1.5 秒，让 #j 加 1
#j 就是这个称重动作的小步号
比如：
#j = 0：开始称重动作
#j = 1：读取重量
#j = 2：结束称重动作
3. 主流程 #i
CASE #i OF
0:
RESET_TIMER(#s);
#j := 0;
IF #nn=221 THEN
#i := 3;
ELSIF #nn=222 THEN
#i := 4;
END_IF;
#nn := 0;
#i = 0 是等待状态。
如果触摸屏或者上位流程给：
#nn = 221
程序进入：
#i = 3
这是第一次称重，记录底重。
如果给：
#nn = 222
程序进入：
#i = 4
这是第二次称重，计算净重。
4. 221 的动作：记录底重
3:
CASE #j OF
0:
“cz2” := 1;
1:
#aa.dhg := “块_1_DB”.cz3[0];
2:
“cz2” := 0;
#i := 0;
END_CASE;
动作过程是：
第 0 步：cz2 = 1，启动称重动作/称重允许
第 1 步：把当前重量保存到 #aa.dhg
第 2 步：cz2 = 0，称重结束，回到等待状态
这里的 #aa.dhg 可以理解为：
底盒重量 / 空盘重量 / 皮重
也就是还没有装料前的重量。
5. 222 的动作：计算净重
4:
CASE #j OF
0:
“cz2” := 1;
1:
#aa.lkg := “块_1_DB”.cz3[0] - #aa.dhg;
2:
“cz2” := 0;
#i := 0;
END_CASE;
动作过程是：
第 0 步：cz2 = 1，再次启动称重
第 1 步：当前重量 - 底重 = 净重
第 2 步：cz2 = 0，称重结束，回到等待状态
这里的 #aa.lkg 就是：
料的重量 / 净重
比如：
第一次空盘重量 #aa.dhg = 100
第二次总重量 = 350
那么 #aa.lkg = 350 - 100 = 250
也就是物料重量是 250。
三站动作可以这样理解
工件到三站称重位置
↓
触摸屏或流程给 #nn = 221
↓
三站第一次称重，记录空盘/底重
↓
后面装料或搬运动作完成
↓
触摸屏或流程给 #nn = 222
↓
三站第二次称重
↓
用总重量减去底重，得到实际物料重量
你的程序里面真正控制动作的主要是 “cz2”：
“cz2” = 1：开始称重/允许称重/可能让称重机构动作
“cz2” = 0：称重结束
具体它现场是控制气缸、夹紧、停止输送线，还是只是给称重仪表一个信号，要看你项目里 “cz2” 实际绑定的点位。
