|浏览量:

数据类型就是在规定一件事：这个变量能存什么样的数据、占多大空间、能做什么运算。

比如：

布尔类型不适合存数量，只适合表示状态。

INTEGER / INT：整数类型

整数类型用来存没有小数的数字。

适合存年龄、数量、次数、排名、步骤编号等。

场景 示例
年龄 age = 18
数量 count = 50
次数 times = 3
排名 rank = 1
步骤编号 step = 2

不同整数类型主要区别是：占用空间不同、能表示的范围不同、能不能表示负数。

类型 大小 大概范围
byte 8 位 0 到 255，或 -128 到 127
short 16 位 约 -3 万到 3 万
int 32 位 约 -21 亿到 21 亿
long 64 位 范围非常大

FLOAT / DOUBLE / REAL：小数类型

小数类型用来存带小数点的数字。

类型 精度 说明
float / real 单精度 占用小，精度一般
double 双精度 占用大，精度更高
decimal 十进制高精度 常用于金额

适合存身高、重量、温度、价格、比例等。
